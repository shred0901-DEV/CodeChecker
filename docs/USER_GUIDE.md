# CodeChecker 利用者マニュアル (User Guide)

CodeChecker は、ソースコードおよびWindows実行バイナリ（EXE/DLL）の脆弱性をハイブリッド方式（静的解析 ＋ AI解説・修正提案）で検出・可視化するデスクトップアプリケーションです。
完全ポータブル設計となっており、OSの環境（`AppData` やレジストリ、システムテンポラリ）を汚さず、アプリフォルダ内ですべて自己完結して動作します。

---

## 1. 起動方法

### ① 通常起動（黒い画面を出さずに起動）
- **`run_silent.vbs`** をダブルクリックします。
- コマンドプロンプトの黒いウィンドウを立ち上げずに、デスクトップアプリの画面だけが直接起動します。

### ② ログ確認用起動
- **`run.bat`** をダブルクリックします。
- コマンドプロンプトが開き、起動ログやエラーメッセージを確認できます。

---

## 2. 脆弱性チェックの基本手順

1. **対象コード・ファイルの指定**:
   - フォルダ、`.zip` ファイル、または `.exe` / `.dll` ファイルをドロップゾーンにドラッグ＆ドロップ（または選択）します。
   - ソースコード（Python, JS/TS, Java, Go, C/C++, PHP 等）に加えて、**Windows実行バイナリ（EXE/DLL）の包括セキュリティ診断**にも対応しています。
2. **スキャン開始**:
   - 「チェック開始」ボタンを押下します。
   - スキャン中は、誤操作を防ぐためサマリーカードおよび一覧・詳細エリアにすりガラス調のぼかしオーバーレイが適用され、ロックされます。
3. **結果の確認 & フィルタ**:
   - 上部の **危険度 [高]・[中]・[低]** カードをクリックして絞り込みが可能です（各カードの左端には危険度カラーバーが表示され、選択中は枠線が内側にハイライトされます）。
4. **詳細 & AI解説の閲覧**:
   - 左側のリストから指摘をクリックすると、右ペインに該当コード（またはバイナリ情報）とAIによる解説・修正提案が表示されます。
   - **EXE/DLLバイナリ指摘のAI解説**:
     - ASLR/DEP/CFG等のエクスプロイト防御策の不備や、危険なAPI呼び出し（`strcpy`, `system` 等）、埋め込みシークレットに対し、AIがコンパイラオプション（Visual Studioの `/DYNAMICBASE`, `/NXCOMPAT`, `/guard:cf` 等）や安全な代替コード（`strcpy_s` 等）を具体的に提案します。
   - **リンクのスマート判別**:
     - 🌐 **Webリンク** (`http://`, `https://`): オレンジ色 `[↗]` で表示され、クリックすると**外部ブラウザ（EdgeやChrome等）**で自動的に開きます（アプリ画面が遷移することはありません）。
     - 📄 **ファイルリンク** (ソースファイル名): スカイブルーの破線下線 `[📄]` で表示され、クリックすると**VS Code等のエディタ**で該当ファイル・該当行を直接開きます。
   - **エディタで開くボタン**:
     - 詳細ペイン上部の「エディタで開く」ボタンを押すと、現在選択中の指摘ファイルをエディタ（VS Codeが利用可能な場合は該当行にジャンプ）で開くことができます。
   - **ZIPファイル検査時のファイル開きと注意通知**:
     - ZIPアーカイブを直接指定・スキャンした場合、アプリ内の一時展開フォルダ（`.temp/`）内のファイルが開かれます。この場合、エディタでファイルを編集・保存しても元のZIPアーカイブには自動反映されないため、画面右下に**警告トースト通知**が表示されます。
   - 右上の「コピー」ボタンで修正提案をクリップボードにコピーできます。
5. **レポートの保存**:
   - 右上の「レポート出力」ボタンをクリックし、Markdown（`.md`）または HTML（`.html`）形式で保存できます。

## 3. AIプロバイダ（Ollama ＆ Codex CLI）の切り替えと設定

画面右側の**脆弱性詳細欄の上部ツールバー**から、AIプロバイダの切り替えやレポート出力を直接操作できます：

| プロバイダ | 説明 |
| :--- | :--- |
| **Ollama (ローカル)** | PC内のローカルLLM（`gemma4:12b-it-q4_K_M` 等）を使用（無料・完全オフライン、タイムアウト240秒対応） |
| **Codex CLI** | OpenAI の `codex` コマンドを使用（自動で非対話 exec モード・`shell=False` で安全に実行） |
| **AI無効 (高速)** | 静的解析のみを瞬時に確認したい場合 |

### プロバイダ切り替えと再生成の仕様
- **脆弱性一覧での生成済み表示**:
  - AIによる解説・修正提案の生成が完了した脆弱性には、一覧リストの該当カード内に「**〇〇によって生成済み**」（例: `Ollamaによって生成済み`、`Codex CLIによって生成済み`）とバッジが表示されます。
  - 推論処理中や再生成中は非表示となり、詳細画面のバッジ描画と完全に同期して表示されます。
- **誤操作防止設計**: AIプロバイダを変更した時点では**自動再生成は行われません**。
  - 現在表示中の解説がどのプロバイダ・モデルで生成されたかは、見出し右隣のバッジで正確に確認できます（例: `Ollama (gemma4:12b-it-q4_K_M)`、`Codex CLI (gpt-4o)`）。
  - 変更したプロバイダで解説を生成したい場合は、「**AI解説を再生成**」ボタンを明示的に押下します。
- **キャッシュの賢い活用**: 変更したプロバイダで同一セッション中に既に生成済みの場合は、APIやCLIを再実行せずキャッシュから即座に表示され、無駄なリソースやトークン消費を抑えます。なお、タイムアウトや通信エラーが発生した場合はキャッシュに保存されないため、いつでも安全に再試行できます。
- **CLIモデルの自動検出**: 設定画面を開くと、PC内のCLI設定（Codexの `config.toml` など）から現在設定されているデフォルトモデルを自動検出し、手動指定がない場合でもそのモデル名が表示・バッジ反映されます。
- **非同期通信の競合保護**: 指摘の連続切り替え時にも、先行リクエストの結果が後から画面を上書きしないよう厳密に検証ガードされ、安全に処理中であることが画面に明示されます。

### 設定の変更と完全ポータブル永続化 (⚙ 歯車アイコン)
- 設定画面を開くと、各CLIのコマンドや使用したいモデル名を自由に指定できます。
- 「テスト実行」ボタンを押すことで、その場でCLIが正常に応答するか導通テストを行えます。
- 「保存して閉じる」ボタンを押下すると、アプリフォルダ内の **`settings.json`** に自己完結保存されます（レジストリやOS領域を汚しません）。
